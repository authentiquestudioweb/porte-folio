03 Publie-le gratuitement

  1. Télécharge ton CV avec le bouton ci-dessus.
  2. Renomme le fichier en index.html.
  3. Va sur app.netlify.com/drop et glisse le fichier dans la page : tu obtiens un lien public en quelques secondes.

Autre option : crée un dépôt GitHub, ajoute-y index.html, puis active GitHub Pages dans les réglages.
