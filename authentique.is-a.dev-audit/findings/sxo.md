**À ne pas viser : « développeur web Ouagadougou »**
Cette recherche est **une recherche d'emploi** : offres de stage LinkedIn, Emploiburkina, salaires, plateformes de freelances. Elle n'amène pas de clients. Garde-la pour LinkedIn, pas pour la page d'accueil.

**Recherche de marque : « authentique dev »**
Ta fiche Authentique-dev apparaît déjà à droite. Le site n'est pas encore indexé. Les concurrents de nom sont 00auth.dev, Français Authentique et Authentik.

## 3. Ce que veulent les visiteurs

Ces besoins sont déduits des signaux de la page de résultats.

1. **Le commerçant pressé** (pack local et formulaires de devis) :
   - il veut un site pour sa boutique ou son entreprise, vite, pour être trouvé et vendre ;
   - il bloque parce qu'il ne sait pas à qui faire confiance ni combien ça coûte.
2. **Le comparateur de prix** (question « Combien coûte la création d'un site web ? », guide zisima en 3e position) :
   - il veut connaître le budget avant d'appeler, pour ne pas se faire avoir ;
   - aucune page ne lui donne de fourchette pour son type de site.
3. **Le futur e-commerçant** (question sur le commerce électronique, page e-commerce de venegre) :
   - il veut vendre en ligne avec Mobile Money, car ses clients paient comme ça ;
   - il bloque parce qu'il ne sait pas si c'est faisable ni pour quel prix.
4. **L'acheteur qui passe par un annuaire** (Sortlist, AlloContact) :
   - il veut comparer plusieurs prestataires avec leurs avis et leurs réalisations ;
   - il bloque parce que les petits prestataires n'ont ni avis ni études de cas.
5. **L'école ou l'association** (la description de ta fiche cite les écoles) :
   - elle veut un site simple et pas cher pour communiquer avec les parents ou les membres ;
   - elle bloque sur les questions techniques, car personne n'est développeur en interne.

**Améliorations, en commençant par le profil le plus faible**
- **Comparateur de prix** : un bloc « À partir de … FCFA » par type de site (vitrine, e-commerce, application), avec ce qui est inclus et le délai.
- **Futur e-commerçant** : une offre « Boutique en ligne avec Mobile Money (Orange Money, Moov Money) », présentée à travers Allo Gaz ou Boutik.
- **École / association** : une offre « Site école / association », avec ce que tu prends en charge (hébergement, mises à jour, formation).
- **Commerçant pressé** : dès le haut de page, une phrase du type « Je crée votre site web à Ouagadougou en X jours » et un bouton « Devis gratuit sur WhatsApp » ; ajouter des avis clients.

## 6. Actions prioritaires

1. **Créer la page `/creation-site-web-ouagadougou/`**. C'est elle qui corrige le décalage de type de page. Contenu :
   - un H1 « Création de site web à Ouagadougou » ;
   - 3 ou 4 offres avec un prix « à partir de » ;
   - la démarche en 4 étapes ;
   - les délais ;
   - 2 ou 3 réalisations avec captures ;
   - une FAQ visible (prix, délais, Mobile Money, hébergement, nom de domaine) ;
   - un bouton « Devis WhatsApp » ;
   - des données structurées Service et Offer.
2. **Ajouter une section « Services » sur la page d'accueil**, juste après le héros, avec les offres et un lien vers cette page.
3. **Fiche Google**, car le pack local passe avant tout :
   - viser 10 avis ou plus (les concurrents en ont 5 à 29) ;
   - remplir les services (« Création de site web », etc.) ;
   - passer en zone de service centrée sur Ouagadougou ;
   - ajouter des photos de réalisations ;
   - publier un post par semaine.
4. **Publier l'article « Combien coûte un site web à Ouagadougou en 2026 ? »**. Il répond à la question que Google met en avant et vise la place de zisima (position 3).
5. **T'inscrire sur les annuaires qui sont en première page** : Sortlist, AlloContact, Codeur.com et AfricaShore. Ils se classent déjà, donc y avoir un profil te rend visible tout de suite.
6. **Ajouter des études de cas avec résultats** (Allo Gaz, Boutik) : captures, problème, solution et chiffres.
7. **Ne pas cibler « développeur web Ouagadougou »** sur la page d'accueil, puisque c'est une recherche d'emploi.
